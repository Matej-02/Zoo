# Pocket Zoo Horizons

A self-contained browser zoo-management prototype. No installation, server, framework, or external assets are required.

## Play locally

Open `index.html` in a modern desktop browser.

## Update GitHub Pages

1. Replace the repository's existing `index.html` with this one.
2. Commit and push the change to the branch used by GitHub Pages.
3. Wait for the Pages deployment to finish.
4. Refresh the game with `Ctrl + F5` if the old build remains cached.

Existing Pocket Zoo saves are migrated automatically. Use **New zoo** only when you want to permanently clear the browser save and restart.

## Horizons changes

- Removable paths and six path styles.
- Gates can replace compatible fence tiles.
- Terrain-aware, biome-specific foliage placement.
- Permanently visible Inspect and Bulldoze tools.
- Live-updating animal, habitat, staff, facility, and tile inspection.
- Collapsible Employees, Objectives, Inspector, and Zoo log sections.
- Visible staff counters and clearer payroll information.
- Easier early economy with lower operating costs, stronger objectives, and temporary founder support.
- Custom SVG construction artwork and Canvas map artwork instead of visible emoji icons.
- Expanded hover explanations for costs, requirements, terrain compatibility, fence ratings, and monthly upkeep.
