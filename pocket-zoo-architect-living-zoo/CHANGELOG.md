# Changelog

## 8.0 — Living Zoo edition

- Replaced the old side-menu layout with a permanent icon-only rail and one closable feature panel.
- Moved all construction categories, management views, finance, land, news, settings, Inspect, and Bulldoze to the left rail.
- Kept visible camera rotation controls beside zoom and the compass.
- Removed the map hover-information window; live information is now Inspect-only.
- Added animal hygiene, grooming, health, illness, aging, juveniles, births, and visible habitat waste.
- Added keeper priorities and task art for treatment, habitat cleaning, washing, grooming, feeding, and patrol.
- Added animal happiness as a zoo-wide condition and reputation input.
- Added the compact Zoo pulse and filterable Zoo news with daily rate limiting and urgent-event priority.
- Added annual financial reports, cleanliness praise, happiness milestones, illness, recovery, birth, staff, objective, and expansion events.
- Improved staff/entity movement so large frame steps cannot trap characters between tiles.
- Rebalanced animal-care workload and verified a 60-day medium-habitat simulation.
- Upgraded save format to version 8 with legacy migration.
- Expanded browser regression coverage from 27 to 33 checks.

## 7.0 — Rotatable 2.5D edition

- Replaced the flat top-down renderer with a diamond-grid 2.5D projection.
- Added four camera directions, camera buttons, Q/E shortcuts, compass feedback, and camera persistence.
- Added inverse projection for construction and inspection from every direction.
- Added depth sorting, animated water, projected land parcels, vertical barriers, and improved vector art.

## 6.0 — Architect modular edition

- Split the single-file game into data, core, systems, rendering, UI, styles, and tests.
- Added catalog validation, legacy-save migration, JSON import/export, monthly finance reporting, and regression tests.
